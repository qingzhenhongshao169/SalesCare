# 源码整理与验证

整理日期：2026-10-14。

此版本从当前SalesCare项目复制，脱离财务项目的Git仓库。没有移动或重新初始化原项目，没有复制运行数据库、真实账号、密钥、日志、上传原件或本机依赖。

保留后端、前端、迁移、维护脚本、合成测试、官方公开知识样例。移除本机运营记录、真实运行状态与截图。新增独立README、新环境设置、两人协作规范、数据处理对接草案和忽略规则。

协作副本有两项小调整：

- 页面验收脚本的Playwright路径改为可配置或常规包路径，不依赖原开发者缓存目录。
- Vite由6.4.1更新为同系列6.4.4补丁版，package-lock.json同步更新。原运行目录保持原版本。

依赖更新依据npm audit的修复提示，相关官方安全公告：

- https://github.com/advisories/GHSA-p9ff-h696-f583
- https://github.com/advisories/GHSA-fx2h-pf6j-xcff

源码包核对包括Python语法、JSON解析、必要源码路径、Git忽略规则、敏感凭据模式扫描、前端严格构建、前端单元检查和ZIP完整性/文件摘要。

没有在此副本运行数据库初始化，也没有连接同事数据库。需要独立开发配置的MVP集成检查、真实外部渠道和联合数据库恢复不属于本次打包验收。

运行数据、依赖和构建产物的排除是刻意的；新机器必须安装依赖、构建前端并配置数据库后才能启动。
