# 周一测试反馈实施与验收

2026-10-19，原标梵8767服务已启用。对应用户提供的《周一测试反馈.txt》及随后确认的修改方案，未另建对客接口或替换企业模型。

## 已实施

- 新增共享 `server/turn_plan.py`：当前任务列表、方向候选及selected/undecided/multiple/unknown状态、预算是否未定、可用案例证据。画像投影、对话辅助数据、生成校验、任务回退与推荐共同使用这些定义。
- “资料准备＋给个案例＋预算未定”分别处理：普通检索去掉未定预算对报价排序的干扰；已审核案例在生成前从原授权知识库补入，合并后最多6条证据。案例候选仅本地查询，不新增Embedding、重排或回答模型调用。
- 保留原关键词/向量融合与重排实现。此次没有完成大规模检索索引或通用RAG重建；案例补召回不代表任意多意图均能拆分。
- 模型在同一次回答中返回answer、knowledge_ids、covered_tasks及case_ids；复合任务和未定方向要求覆盖声明，并核对实际正文与案例来源。单任务保留部分格式兼容，实际覆盖仍由本地守卫检查。覆盖声明不是语义正确性的充分证明。
- 卡片在投递前按权限、版本、当前消息和租约重查，并限制在生成前候选和实际引用证据内。正文与卡片共用案例；来源撤回或改版时不发送旧证据，不将“本轮没找到”说成企业从未做过。
- 方向未定时，画像显示“企业官网 / 管理系统（未定）”，confirmed为false，暂停方案/案例推送。比较获客展示与内部流程；用户明确选择后再更新方向。泛称“系统”在网站/系统选择语境中可识别；未来再考虑的方向不作为当前选择。
- 预算未定显示“未定”，没有金额值；8w换算和9万省略更正回归保留。
- 生成失败、漏答、虚报覆盖或来源变化时，按同一任务清单完成有来源支持的回答。通用方向比较可不附企业事实引用，但无引用的企业能力或承诺仍被阻止。
- 已核实来源URL里的路径数字不作为未核实金额拦截，也不授权任何报价；仅过滤有效HTTP(S)来源或规范文档来源路径，普通“报价99999元”字符串不能伪装成URL绕过校验。
- 模型提示和任务回退使用短句、少复述、最多一个必要问题，允许按场景适量使用语气词；没有在生成后机械追加“哦～”。部分建议仍带顾问限定，表达自然度仍需人工复核。
